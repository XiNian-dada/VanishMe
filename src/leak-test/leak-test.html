💡 为什么此测试不会触发 Chrome 的 geolocation 权限警告？

在旧版本中，内置测试页直接调用 Chrome 原生 navigator.geolocation，因扩展未在 manifest.json 中声明 geolocation 权限而报错。 而在普通网站中，VanishMe 会自动拦截定位请求并直接返回配置好的虚拟海外坐标。 现在本测试页与普通网站完全对齐：当开启定位伪装时，调用完全在受保护接口中运行，既不向 Chrome 申请敏感物理权限（避免刺探用户真实物理坐标），也不会产生任何警告！
